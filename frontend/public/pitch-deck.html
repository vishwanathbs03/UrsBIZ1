Slide 02 / 08 The Problem

What We Heard From MSME Founders

Manual Reporting, Scheme Discovery Across Portals, No Forward View
  • Fragmented scheme discovery: Founders navigate multiple ministry portals (msme.gov.in, nsic.co.in, kvib.gov.in) to find applicable subsidies.
  • Manual reporting for bank loans: Reports are re-typed from spreadsheets and ledgers for every CA or banker review.
  • No forward-looking view: Most founders we spoke to rely on intuition for the next 3–12 months of cash flow.
  • No single source of truth: Profile details (turnover, sector, workforce, state) are re-entered on every form.
🎤 Key Message: We did not claim a national-failure statistic. The problem statement comes from founder interviews; replace with your own pilot interviews if presenting.

Slide 04 / 08 AI Architecture

How The AI Layer Is Built

Deterministic First, Generative Synthesis Grounded In The Evidence Bundle
  • Deterministic engines: Profile Readiness Score, Scheme profile-match, Scenario horizons are rule-driven and reproducible.
  • Grounded synthesis: An optional OpenAI-compatible provider rewrites the evidence bundle in natural language. Provider falls back to a safe placeholder if no API key is set.
  • No embeddings, no vector store: The repo explicitly ships without vector search. Retrieval is from the deterministic engine outputs.
  • Trust labels in UI: Every value is tagged rule-engine, scenario estimate, retrieved, or generated.
🎤 Honesty Statement: We removed "Zero-Hallucination" and "Hybrid RAG" from earlier drafts because the codebase does not contain a vector layer.

Slide 06 / 08 Security & Operations

Honest Security & Ops Posture

JWT HS256, HTTPOnly Cookies, Container Compose, /health Endpoints
  • Auth: JWT signed with HS256, delivered via the atlas_access_token HTTPOnly cookie. No OAuth provider.
  • At-rest encryption: None — we did not implement AES-256 envelope encryption. Document the deployment's DB-at-rest posture separately if relevant.
  • Deployment: Docker Compose (nginx + backend + frontend + prometheus + grafana) or native uvicorn + standalone Next.js.
  • Health & readiness: /api/v1/health/live (process liveness) and /api/v1/health/ready (DB + knowledge base + AI provider + migrations).
🎤 Key Message: We removed "sub-50ms latency" and "AES-256" claims because no benchmark exists and the codebase uses HS256 JWTs, not AES-256.
