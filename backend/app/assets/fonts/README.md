# Bundled Fonts for UrsBiz Reports & Evidence Export Centre

This directory contains bundled open-source TrueType fonts to ensure deterministic, reliable cross-platform Unicode and Indic script rendering (specifically Kannada) in generated PDF reports.

## Fonts Included:
- **NotoSansKannada-Regular.ttf**:
  - Source: Google Fonts ([noto-fonts](https://github.com/googlefonts/noto-fonts))
  - Coverage: Complete Unicode Kannada block (`U+0C80` through `U+0CFF`), Latin alphabet, digits, and standard punctuation.
  - License: SIL Open Font License, Version 1.1 (OFL)
  - Purpose: Embedded into ReportLab PDF documents to provide full native glyph coverage for Kannada MSME business names (e.g., `ಶ್ರೀ ಬಸವೇಶ್ವರ ಎಂಟರ್‌ಪ್ರೈಸಸ್`) across all client platforms.
